Aim

To determine the overall transfer function of a control system using Signal Flow Graph (SFG) analysis and Mason's Gain Formula.

Apparatus Required

  • Computer / Laptop
  • Scilab Software
  • Internet Browser
  • Virtual Control System Laboratory
  • Control System Toolbox

Theory

A Signal Flow Graph (SFG) is a graphical representation of the functional relationships among system variables. It consists of nodes connected by directed branches, where each branch is associated with a gain that represents the relationship between two variables.

Signal Flow Graphs provide a convenient method for analyzing complex control systems. The overall transfer function can be determined directly from the graph using Mason's Gain Formula, eliminating the need for extensive block diagram reduction.

T = Σ(PkΔk) / Δ

where:

  • Pk = Gain of the kth forward path
  • Δ = Determinant of the graph
  • Δk = Determinant obtained by removing loops touching the kth forward path

The determinant Δ is calculated using:

Δ = 1 − (Sum of Loop Gains) + (Sum of Products of Two Non-Touching Loops) − (Sum of Products of Three Non-Touching Loops) + ...

Mason's Gain Formula provides a systematic and efficient approach for obtaining the transfer function of a system represented by a signal flow graph.

Procedure

  1. Draw the signal flow graph for the given control system.
  2. Identify all forward paths from input node to output node.
  3. Calculate the gain of each forward path.
  4. Identify all individual loops and determine their loop gains.
  5. Determine all possible non-touching loop combinations.
  6. Calculate the graph determinant (Δ).
  7. Calculate Δk for each forward path.
  8. Apply Mason's Gain Formula.
  9. Determine the overall transfer function.
  10. Verify the result using Scilab simulation.

Result

The overall transfer function of the given signal flow graph was successfully determined using Mason's Gain Formula. The analytical result was verified using Scilab simulation.
