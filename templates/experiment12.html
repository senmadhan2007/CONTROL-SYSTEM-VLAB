Aim

To reduce a complex control system block diagram into its equivalent transfer function using block diagram reduction techniques such as series, parallel, and feedback combinations.

Apparatus Required

  • Computer / Laptop
  • Scilab Software
  • Internet Browser
  • Virtual Control System Laboratory
  • Control System Toolbox

Theory

Block diagram reduction is a graphical method used in control systems to simplify complex interconnected systems into a single equivalent transfer function. It enables engineers to analyze the overall performance and behavior of a system without dealing with its internal complexity.

A block diagram consists of functional blocks representing system components, summing points, and take-off points. The reduction process involves systematically combining these elements according to standard reduction rules.

  • Series Combination: When two or more blocks are connected in series, the equivalent transfer function is the product of individual transfer functions.
  • Parallel Combination: When blocks are connected in parallel, the equivalent transfer function is obtained by algebraic addition or subtraction of the transfer functions.
  • Feedback Combination: For a feedback system, the equivalent transfer function is:

T(s) = G(s) / [1 + G(s)H(s)]

By repeatedly applying these rules, a complex block diagram can be reduced into a single transfer function representing the complete system.

Procedure

  1. Study the given block diagram carefully.
  2. Identify all transfer function blocks, summing points, and take-off points.
  3. Combine blocks connected in series by multiplying their transfer functions.
  4. Combine blocks connected in parallel by adding or subtracting their transfer functions.
  5. Apply feedback reduction formulas wherever feedback loops exist.
  6. Shift summing points and take-off points when necessary using standard block diagram reduction rules.
  7. Repeat the reduction process until a single equivalent block is obtained.
  8. Determine the overall transfer function of the system.
  9. Verify the result using Scilab simulation.

Result

The given control system block diagram was successfully reduced using block diagram reduction techniques. The overall equivalent transfer function of the system was obtained and verified through simulation.
